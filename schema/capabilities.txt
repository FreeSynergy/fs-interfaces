# Capability names (ADR 0068): ONE list, read by fs-store (fs_interfaces::capabilities) and planned for the catalog generator
# (fs-catalog/scripts/gen_catalog.py). One line per capability, fields separated by `|`, spaces around them ignored:
#   key | display name | status | description
# key: lower-case dotted machine name (`topic` or `topic.facet`); a topic key is the name of its schema in fs-interfaces
#   (ADR 0068). display name: for people ("Boards" for key `whiteboard`); the pair lives here and nowhere else.
# status: `stable` (the interface exists) or `planned` (named, not built yet; is_known is true, is_planned tells).

# `#` starts a comment line.
